# Проверка запуска для жюри и опциональных возможностей

Проверено 23 сентября 2026 года на Windows, Python 3.12.14.
Основа ветки — `2ab2702` (main после PR №8 и №9). Отпечаток кода агента и
проверки: `8f838c658cfb`; он вычисляется в `jury_eval.version()` из пяти
файлов кода/зависимостей и выводится в панели. Это не Git-коммит.

## Выполнено

- `run.py` и `start.cmd`: создание `.venv`, установка закреплённых
  зависимостей, импорт ZIP/каталога организаторов, запуск локальной панели.
- Прямой ZIP-импорт проверен на предоставленном пакете. Все 7 исходников
  организаторов и 7 CSV совпали с манифестом. Исходные файлы не изменены.
- Сохранены учёт неопределённости и адаптивные повторные пилоты. Публичные
  коэффициенты каналов теперь помогают выбирать следующий эксперимент;
  финальный выбор канала по-прежнему требует его собственных наблюдений.
- Добавлены LLM-ранжирование гипотез и журнал решений для интерфейса.
  Модель не получает абонентские строки и не возвращает финальные кампании.
- README описывает быстрый запуск, сценарий демонстрации и пять опциональных
  пунктов раздела 8 ТЗ. Официальные evaluator/exporter остаются неизменными.

## Проверки

`python run.py --check` успешно выполнен и в исходном подготовленном
окружении, и после создания новой `.venv` и установки зависимостей из PyPI.
Первый сетевой запрос установки в песочнице завершился таймаутом; повтор
в разрешённом сетевом окружении прошёл. Активация PowerShell не использовалась.
`pip check` не обнаружил несовместимых зависимостей.

Windows-обёртка дополнительно проверена командой `start.cmd --check` при
отсутствии `python` и `py` в PATH: использована существующая `.venv`, код
возврата 0. Проверены запуск агента из браузера на seed 0 и 42, журнал
решений, отображение серии проверок и скачивание `submission.csv`.
В журнале браузера нет ошибок и предупреждений. HTTP API отклоняет
неверный тип seed (400) и запрос с посторонним Origin (403).

Команда проверила seed 42 и десять seed 0–9. Для каждого прогона отдельно
проверены тарифы, каналы, размеры аудиторий, количество и размеры пилотов,
бюджет и контакты с учётом финального плана. Результаты сопоставлены с

- выбор SMS и звонка при разных наблюдаемых эффектах и ценности аудитории;

- отсутствие запросов без ключа или при выключенном LLM;
- запасную логику при неверных, неполных ответах и зависании транспорта;
- безопасный импорт вложенного ZIP и сохранение отличающихся локальных CSV.

## Границы результата

API-контракт сверён с официальной документацией. После автоматических
тестов выполнен один живой запрос с временным ключом пользователя:
HTTP 200, 3,781 секунды, `llm_status=applied`. Полный `Agent.act` занял
4,590 секунды. Seed 42: PASS, +372 925,00 у.е., 20 пилотов, 1 кампания,
1 444 контакта, расходы 0. Без LLM на том же seed: +389 987,36 у.е.
Преимущество LLM по прибыли не подтверждено; один прогон не является
статистической оценкой. Воспроизводимая серия выполнена без LLM.

Ключ передавался скрытым вводом только временному процессу и удалён из его
окружения после проверки. В исходники, `.env` и артефакты он не записывался.
Локальный отчёт `artifacts/llm-live.json` содержит только метрики и статус API.

Мок-эффекты отличаются от скрытых эффектов судейства. Ни положительные
прогоны, ни эвристическая стандартная ошибка не гарантируют результат на
произвольных эффектах. Проверка Linux/macOS отдельно не выполнялась.
Агент проверяет дедлайн между пилотами; жёсткие 600 секунд обеспечиваются
обёрткой запуска, а не изменениями официальных файлов.
