# План и результаты локальной QA

Проверяется синтетическая среда команды из main `688581e`, не пакет
организаторов. PASS относится только к указанной команде и окружению.
FAIL означает расхождение с ожидаемым результатом; NOT_RUN — проверка ещё
не выполнялась. NOT_RUN не заменяется на PASS по наличию команды в README.

Первичный прогон: Windows, Python 3.12.0, отдельный bootstrap venv,
NumPy 2.3.5, pandas 3.0.1. OPENAI_API_KEY удалён из окружения дочерних процессов
без чтения/вывода его значения. Чистое повторение и окончательная проверка
README завершены на этапе 4 и зафиксированы в [test-report.md](test-report.md).

## Команды

Все команды — из корня проекта с активированным venv.

| ID | Команда |
| --- | --- |
| I | `python -c "from agent import Agent; assert callable(Agent().act); print('Agent import OK')"` |

| R | `python local_eval.py --runs 10` |

| H | `Get-FileHash submission.csv -Algorithm SHA256` после каждого из двух запусков S |
| U | `python -m unittest discover -s tests -v` |

| K | `Remove-Item Env:OPENAI_API_KEY -ErrorAction SilentlyContinue; python local_eval.py` в отдельной PowerShell-сессии |
| C | Установка и основной сценарий README в новом venv; точные команды в test-report.md |
| D | `git diff --check` и проверка команд/путей README по файлам и CLI `--help` |

Ссылка на ID в таблице ниже означает точную команду из этой таблицы. E/J
с seed 42 используют фиксированную базу генератора seed 2026. R меняет только
seed среды (42–51). По JSON проверяются не только слова в stdout, но и
числовые значения metrics, campaigns и pilot_history.

## Ограничения

Прогон организаторов не выполнялся. Набор IBM проверяет только чтение CSV.
Прохождение локальных тестов не устанавливает судейский балл или оптимальность
агента. Этап финальной интеграции и слияние PR не выполняются этим тест-планом.
