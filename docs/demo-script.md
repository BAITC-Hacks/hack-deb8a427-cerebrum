# Сценарий демонстрации Cerebrum

Это план показа, а не отчёт о уже выполненных проверках. Используйте
[официальный пакет участника](../PARTICIPANT_GUIDE.md) и команды из
[README](../README.md). Все данные пакета синтетические; локальные
мок-эффекты не предсказывают судейский результат.

## Подготовка

1. Установите зависимости и импортируйте пакет в чистой рабочей копии.
2. Убедитесь, что исходные CSV корня и `data/` доступны локально, а Git
   их игнорирует.
3. Не показывайте содержимое `.env`, токены, локальные пути участников
   или полные строки CSV на публичном экране.

## Показ

1. Кратко объясните задачу: выбрать аудиторию, тариф и канал при
   ограничении бюджета, контактов и числа пилотов.
2. Покажите в `agent.py` точку входа `Agent.act(env)` и в
   `candidates.py` построение вариантов. История из пакета относится
   к другой выборке; решение уточняется пилотами на целевой аудитории.
3. Запустите официальный evaluator:

   ```powershell
   python local_eval.py
   python local_eval.py --runs 10
   ```

4. Одиночный запуск использует seed 42, десять прогонов — seed 0–9.
   В фактическом текстовом выводе проверьте отсутствие `FAIL` и отброшенных
   кампаний, затем отметьте число пилотов, использованные контакты и расходы.
   Код возврата 0 сам по себе не подтверждает зачёт. Не подставляйте
   прежние метрики симулятора команды.
5. Создайте файл сдачи официальным экспортёром:

   ```powershell
   python make_submission.py
   Test-Path submission.csv
   Get-Content submission.csv -TotalCount 5
   ```

6. Назовите границу проверки: локальный evaluator использует
   мок-эффекты, а на судействе эффекты другие. Успешный локальный
   прогон подтверждает работу на этом пакете, но не будущий балл.

После проверки добавьте `submission.csv` в Git: это обязательный
артефакт сдачи. Входные CSV пакета и `data/` остаются локальными.

Для описания проекта в форме сдачи используйте фактический результат
текущего коммита из [test-report.md](test-report.md) после завершения
финальных проверок. Не копируйте в заявку цифры архивных тестов.
