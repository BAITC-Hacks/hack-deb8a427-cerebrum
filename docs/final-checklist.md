# Чек-лист перед сдачей

Отметки ставятся после фактической проверки текущего коммита. Источник
условий — [PARTICIPANT_GUIDE.md](../PARTICIPANT_GUIDE.md). Время и способ
отправки уточняет капитан по правилам площадки.

## Пакет и репозиторий

- [ ] Официальные скрипты и `PARTICIPANT_GUIDE.md` совпадают с исходным
  пакетом по манифесту; скрипты не изменены.
- [ ] CSV корня и `data/` восстановлены локально командой импорта и
  исключены из Git.
- [ ] `git status` и `git diff --cached --name-only` не показывают
  входные CSV, `.env` или секреты; проверенный `submission.csv` включён в Git.
- [ ] Python окружение установлено из `requirements.txt`;
  `python -m pip check` завершился успешно.

## Агент и проверки

- [ ] `python run.py --check` прошёл; `artifacts/validation.json` относится
  к текущей версии. Экспорт проверен без LLM.
- [ ] `start.cmd` или `python run.py` открывает панель из чистой копии проекта.
- [ ] В сдачу включён `llm_advisor.py` вместе с `agent.py` и `candidates.py`.
- [ ] Если заявлена работа с живой LLM, отдельно проверены API-ключ и модель;
  автоматические тесты транспорта не выдаются за живой API-прогон.

- [ ] `python scripts/preflight.py` прошёл.
- [ ] `python -m unittest discover -s tests -v` прошёл.
- [ ] В текстовом отчёте `python local_eval.py` нет `FAIL` и отброшенных кампаний:
  есть пилоты, от 1 до 10 кампаний и соблюдены лимиты.
- [ ] В отчёте `python local_eval.py --runs 10` проверены seed 0–9;
  результаты рассмотрены, а не сведены к одному удачному запуску.
- [ ] `python make_submission.py` создал непустой `submission.csv`
  официального формата, файл проверен и добавлен в Git.
- [ ] Итоги, коммит и ограничения записаны в
  [test-report.md](test-report.md) по фактическому выводу.

## Отправка

- [ ] Капитан сверил обязательные файлы, ссылку на репозиторий,
  способ сдачи и текущий дедлайн.
- [ ] Описание не называет мок-результат судейским баллом и не делает
  выводов о реальном бизнесе по синтетическим данным.
