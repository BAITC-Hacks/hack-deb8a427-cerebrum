# Архив: синтетический набор команды

До получения официального пакета команда подготовила собственный набор
`synthetic_case/` и генератор `generate_case_data.py` для локальных
экспериментов. Генератор удалён из рабочего сценария. Его данные и
результаты прежнего evaluator не подтверждают поведение на официальном
пакете участника.

Для текущей работы используйте только предоставленные организаторами CSV,
восстановленные локально по [README](../README.md). Источник требований —
[PARTICIPANT_GUIDE.md](../PARTICIPANT_GUIDE.md). Прежний симулятор и
демонстрационный генератор используются только поддержкой тестов в
`tests/support/`; они не готовят вход для `local_eval.py` и
`make_submission.py`.

Все данные официального кейса описаны организаторами как синтетические.
Исторические файлы `data/` относятся к другой выборке абонентов; они
помогают формировать гипотезы, но не раскрывают эффект кампаний на целевой
аудитории. Реальный бизнес Beeline по этим данным оценивать нельзя.
