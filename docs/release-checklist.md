### Чистая установка

До запуска `.venv` отсутствовала. Первая попытка создала окружение, но доступ
к PyPI из ограниченного окружения завершился таймаутом установщика через
180 секунд; данные ещё не импортировались. Повторена та же команда запуска
с разрешённым сетевым доступом. Окружение не копировалось из другой рабочей
папки; зависимости установлены через `pip install -r requirements.txt` самим
`run.py`. Использованы колёса из кеша pip, новая `.venv` при этом независима.

Установлено: NumPy 2.3.5, pandas 3.0.1; транзитивно — python-dateutil
2.9.0.post0, six 1.17.0 и tzdata 2026.4. Перенос существующей `.venv`,
ручное исправление официальных файлов и установка дополнительных библиотек
для прохождения проверки не применялись.

## Known limitations

- Подтверждены Windows и Python 3.12.14. Linux/macOS и другие версии Python
  отдельно не запускались.
- Для первой установки нужен доступ к PyPI; ограничение сети среды проверки
  потребовало повторной установки. Прямые зависимости закреплены, полного
  lock-файла транзитивных зависимостей нет.
- Полный набор тестов и проверки репозитория требуют Git и Git-копию.
  Запуск панели и `--check` из ZIP не требуют Git; это различие отражено в README.
- Свежий живой запрос к LLM не выполнялся. Тесты проверяют транспорт через
  подмену и отсутствие запросов без ключа; это не подтверждение доступности
  внешнего API. LLM не обязательна для базового режима и CSV сдачи.
- Мок-эффекты и эвристическая неопределённость не гарантируют качество на
  скрытой судейской среде. Положительность 11 запусков не доказывает оптимальность.
- Проверка секретов ограничена сигнатурами и доступными текстами Git.
  Gitleaks не установлен; базы уязвимостей зависимостей не проверялись.
- Публичная deployed-версия в репозитории не подтверждена; предусмотрена
  локальная демонстрация.
- Точный организационный дедлайн и полное Положение не подтверждены.
  Правило планирования и действия капитана — в [чек-листе сдачи](final-checklist.md).
