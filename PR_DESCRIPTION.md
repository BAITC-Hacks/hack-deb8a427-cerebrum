# Название PR

Добавить фундамент агента тарифных кампаний с пилотами и локальными проверками

# Описание PR

В репозитории не было исполняемого пакета кейса. Добавлены `Agent.act(env)`,
воспроизводимые синтетические данные, неофициальная локальная среда, запуск
с таймаутом, проверки ограничений и экспорт демонстрационного CSV.

Агент использует публичные таблицы и результаты реальных вызовов `run_pilot`
локальной среды, резервирует ресурсы финальных кампаний и учитывает стоимость
контактов. Комбинации для финального плана выбираются после успешных пилотов.
Пилоты и финальные кампании совместно учитываются в бюджете и контактном лимите.
При неблагоприятных наблюдениях возможен отрицательный результат; эвристическая
оценка не гарантирует прибыль или оптимальность.

Среда, evaluator, тарифы и абоненты созданы командой. Это фундамент по описанию
кейса, а не восстановленный официальный пакет. Совместимость с официальным API,
форматом сдачи и судейский балл требуют отдельной проверки после получения
пакета организаторов. Агент не использует внутренности симулятора, внешние API,
LLM или секреты.

## Проверка

Воспроизводимые команды из корня репозитория после установки зависимостей:

```powershell
python -m unittest discover -s tests -v
python local_eval.py
python local_eval.py --runs 10
python local_eval.py --runs 10 --scenario adverse
python local_eval.py --runs 10 --scenario channel_shift
python make_submission.py
git diff --check
```

Подтверждённые локальные результаты:

- Основной seed 42: 3 кампании, 20 пилотов, 10 775 контактов, расходы 97 842,
  `net_gain=2708120.55`; время `act` 0,296 с на машине проверки.
- `--runs 10`: 10/10 допустимых планов, положительный результат в 10/10.
- `--runs 10 --scenario channel_shift`: 10/10 допустимых планов.
- `--scenario adverse`, seed 42: 1 кампания, 20 пилотов, 1 264 контакта,
  расходы 2 040, `net_gain=-273171.77`. Убытки учтены, лимиты соблюдены.
- Генерация CSV и `--data-dir demo_data` дали совпадающий основной результат.
- Два запуска `make_submission.py` дали одинаковый SHA-256 CSV:
  `DD0DCFFB1C9E937C9E5377003A4C975960BF7E4C9640936AD91A0F96D83E17EB`.

`python -m unittest discover -s tests -v`: 18 тестов пройдены за 2,628 с.
`python local_eval.py --agent agent_template`: 2 пилота и 1 допустимая кампания.
`python local_eval.py --timeout 0.01`: ожидаемый таймаут, код возврата 1.
Компиляция Python-файлов прошла; проверка известных сигнатур секретов совпадений
не обнаружила. Это не проверка официального пакета и не аудит безопасности.
Официальные проверки и судейская оценка пока недоступны.

## Ограничения

- Локальный контракт нужно сверить с официальным `env`.
- Синтетические сценарии не воспроизводят настоящую базу и скрытые эффекты.
- Ограниченное исследование и перенос оценки пилота на суженную аудиторию могут
  привести к неоптимальному плану.
- Внутренний дедлайн агента проверяется между вызовами; зависший внешний `env`
  должен прерываться оболочкой исполнения. Локальная оболочка использует процесс
  с таймаутом до 600 секунд.
