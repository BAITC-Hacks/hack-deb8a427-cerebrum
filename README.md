# Cerebrum — агент тарифных маркетинговых кампаний

Cerebrum помогает маркетинговому аналитику выбрать аудиторию, целевой тариф
и канал коммуникации. Кампании вслепую могут привести к downsell и расходам
без результата. `Agent.act(env)` проверяет варианты пилотами и возвращает
ограниченный план кампаний; локальный evaluator оценивает его, а отдельный экспортёр сохраняет CSV.

**Все используемые здесь данные и эффекты синтетические. Выводы нельзя
переносить на реальный бизнес Beeline или другого оператора.** Среда, генератор,
шаблон и evaluator созданы командой и не являются официальным пакетом
организаторов. Локальные результаты не являются прогнозом судейского балла.

## Что реализовано и как запустить основной сценарий

Реализованы агент с пилотами и контролем ресурсов, синтетическая среда с тремя
сценариями, запуск в отдельном процессе с таймаутом, экспорт плана,
CSV-профилировщик, unit tests и preflight. Веб-интерфейса и развёрнутого сервиса нет.

Путь данных: генератор или два входных CSV → публичный env → кандидаты агента
→ пилоты и оценки → список кампаний → локальная валидация → `submission.csv`.
`make_submission.py` повторно запускает агента на том же seed перед экспортом.

## Требования и установка

Нужны Python 3.11+ (ограничение закреплённых NumPy/pandas), Git и CPU.
Проверяемое окружение: CPython 3.12.0, Windows x86-64, PowerShell. Другие ОС
отдельно не проверены. GPU, LLM и API-ключ не нужны. Интернет требуется для
получения репозитория и установки пакетов; расчёты выполняются локально.

Откройте корень официального репозитория команды, где лежит requirements.txt.
Создайте **новое** окружение; если `.venv` уже существует, для чистой проверки
используйте отдельную рабочую копию этого же репозитория. Исходные данные в Git
копировать не требуется.

```powershell
python --version
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --no-cache-dir -r requirements.txt
python -m pip check
python -c "import sys, numpy, pandas; assert sys.prefix != sys.base_prefix; assert numpy.__file__.startswith(sys.prefix); assert pandas.__file__.startswith(sys.prefix); print(sys.version.split()[0], numpy.__version__, pandas.__version__)"
```

Если PowerShell запрещает Activate.ps1, не меняйте политику системы: используйте
`.\.venv\Scripts\python.exe` вместо `python` во всех последующих командах.
На других платформах путь к интерпретатору окружения отличается; этот документ
проверяет именно Windows-сценарий.

Прямые зависимости: NumPy 2.3.5 и pandas 3.0.1. Pip устанавливает также
python-dateutil, six и на Windows tzdata. Их версии не закреплены в requirements;
фактические версии чистой установки перечислены в [THIRD_PARTY.md](THIRD_PARTY.md).
Для фиксации конкретного окружения используйте `python -m pip freeze`.

## Окружение и отсутствие внешнего API

Для основного сценария переменные окружения не требуются. `OPENAI_API_KEY`
в `.env.example` пуст и зарезервирован для возможной будущей интеграции;
текущий агент его не читает и автоматически `.env` не загружает. Значения
ключей нельзя помещать в код, документацию, CLI или логи.

Отдельного сетевого fallback сейчас нет: весь алгоритм изначально локальный,
поэтому недоступность внешнего API не затрагивает расчёт. Если сервис будет
добавлен позже, нужны timeout, try/except и проверенный локальный путь.
При `ValueError`/`RuntimeError` из пилота агент может попробовать следующий
вариант. Если успешных пилотов нет, он завершает работу ошибкой, а не выдаёт
непроверенный план. Плохие наблюдения могут привести к убыточной малой кампании.

## Запуск и критерии успешности

```powershell
python -c "from agent import Agent; assert callable(Agent().act); print('Agent import OK')"
python local_eval.py
python local_eval.py --runs 10
python make_submission.py
Test-Path submission.csv
Get-FileHash submission.csv -Algorithm SHA256
```

Успех основного прогона: код возврата 0, строка `OK`, 1–10 кампаний,
пилотов больше нуля, `contacts` ≤15000 и `cost` ≤100000. Серия должна закончиться
`Completed 10/10`. Локальная среда проверяет весь план и возвращает ошибку при
недопустимой кампании; отсутствие слова «отброшена» само по себе недостаточно.
Положительная прибыль не является условием прохождения проверки лимитов.

`local_eval.py` по умолчанию использует seed 42 и сценарий mixed; `--runs 10`
проверяет seed 42–51. `--json` выводит campaigns, pilot_history, metrics и время.
Каждый запуск создаёт новую среду. Не приписывайте среде скрытые эффекты судейства.

```powershell
python local_eval.py --json
python local_eval.py --runs 10 --scenario adverse
python local_eval.py --runs 10 --scenario channel_shift
python -m unittest discover -s tests -v
python scripts/preflight.py
```

Сценарий adverse может давать отрицательный net_gain при допустимом плане.
Успешный preflight не заменяет запуск evaluator и не является полным аудитом.
Фактические результаты и время команд — в [отчёте QA](docs/test-report.md),
перечень проверок — в [тест-плане](docs/test-plan.md).

Для проверки отсутствия зависимости от ключа откройте отдельную PowerShell-
сессию с активированным venv и выполните (значение ключа не выводится):

```powershell
Remove-Item Env:OPENAI_API_KEY -ErrorAction SilentlyContinue
python local_eval.py
```

Для проверки повторяемости выполните `python make_submission.py` и
`Get-FileHash submission.csv -Algorithm SHA256` дважды. При одинаковых данных,
seed и версиях должны совпасть байты **двух генераций**; Git может менять
LF/CRLF при checkout. Экспорт записывает UTF-8 и LF.

## submission.csv

Это демонстрационный план, не персональная выгрузка. Поля в порядке экспорта:
`campaign_name`, `filter_arpu_segment`, `filter_data_segment`,
`filter_call_segment`, `filter_current_tariff`, `target_tariff`, `channel`.
Пустой фильтр означает отсутствие ограничения по этому признаку, `;` внутри
фильтра объединяет категории. Число строк данных — число кампаний.
CSV не содержит историю пилотов: она находится в JSON-отчёте evaluator.

Экспорт запускается только после успешного локального прогона и перезаписывает
указанный выходной файл. Опции `--output`, `--seed`, `--scenario`, `--data-dir`
описаны в `python make_submission.py --help`. Папка для --output должна уже
существовать. Официальный формат сдачи пока не подтверждён.

## Датасеты и профиль

По умолчанию данные создаются в памяти: 23 441 абонент, 21 тариф, seed генератора
2026. `customer_profile` содержит ID, текущий тариф, три сегмента и predicted_arpu;
`tariff_dictionary` — ID тарифа, monthly_fee, data_gb и minutes. Исторических
смен тарифов, traffic и arpu_monthly в генераторе нет.

Для проверки пути чтения CSV используйте новую временную папку вне репозитория:

```powershell
$demoDir = Join-Path ([IO.Path]::GetTempPath()) ('cerebrum-demo-' + [guid]::NewGuid().ToString('N'))
python generate_demo_data.py --output "$demoDir" --seed 2026
python local_eval.py --data-dir "$demoDir"
python make_submission.py --data-dir "$demoDir" --output "$demoDir/submission.csv"
```

Генератор отказывается перезаписывать свои существующие CSV. Для профиля
передайте отдельную папку только с входами и словарями: корень репозитория
с submission.csv профилировщик намеренно отвергает. Полная команда, профиль
и QA-словарь сегментов описаны в [docs/data-profile.md](docs/data-profile.md).

Небольшой внешний IBM Telco Churn ранее использовался только для теста чтения
CSV. Он не нужен для запуска и не подменяет тарифные данные, сегменты или
predicted_arpu; в Git он не сохранён. Официальных CSV организаторов пока нет.

## Архитектура и структура репозитория

```text
agent.py                   Agent.act(env), кандидаты, пилоты, выбор плана
agent_template.py          минимальный пример команды
local_env.py               публичный контракт, mock-среда, контроль лимитов
local_eval.py              отдельный процесс, timeout, текстовый/JSON-отчёт
make_submission.py         повторная проверка и CSV-экспорт
generate_demo_data.py      генерация двух CSV
analysis/profile_data.py   профилирование CSV без импорта evaluator
scripts/preflight.py       статические проверки без вывода секретов
tests/                     тесты агента, среды, profiler и preflight
docs/                      профиль, тест-план, отчёт, демонстрация, чек-лист
requirements.txt           закреплённые прямые зависимости
.env.example               пустой пример, текущему агенту не нужен
SECURITY.md                правила безопасности и ограничения preflight
THIRD_PARTY.md             версии и лицензии компонентов
submission.csv             воспроизводимый демонстрационный артефакт
```

Агент получает только публичные таблицы/остатки ресурсов и вызывает run_pilot.
Evaluator создаёт среду, вызывает Agent, валидирует результат и считает метрики.
Profiler и preflight являются отдельными инструментами QA и не влияют на выбор
кампаний. Приложение не использует модели машинного обучения, LLM или внешние
API при запуске; зависимости — Python, NumPy и pandas.

## Как агент принимает решения

Агент строит непересекающиеся аудитории по публичным сегментам, при необходимости
делит их по текущим тарифам и звонкам. Сначала исследует комбинации тарифа и
аудитории на самом дешёвом доступном канале, затем использует наблюдённые средние
и стандартные ошибки для повторных пилотов, исследования тарифов и других каналов.

На пилоты выделяется до 25% начального бюджета и до 2 000 контактов; отдельно
резервируются ресурсы хотя бы для одной представимой финальной аудитории.
Остатки ресурсов проверяются перед каждым пилотом. Финальные комбинации тарифа,
канала и исходной аудитории должны иметь успешный пилот. При нехватке ресурсов
финальная аудитория сужается реальными категориальными фильтрами.

Кампании ранжируются по оценке `(средний эффект − стандартная ошибка − цена
контакта) × размер аудитории`. Если положительных кандидатов нет, агент выбирает
малую проверенную аудиторию с наилучшей оценкой, поскольку требуется минимум
одна кампания. Убыток при этом возможен. Стандартная ошибка здесь — эвристика,
не доказанная доверительная гарантия после адаптивного выбора и сужения аудитории.

`agent.py` не импортирует симулятор, не обращается к приватному состоянию среды,
не использует `closure`, `gc`, `inspect`, сетевые запросы или LLM.
API-ключи для работы не нужны. Если внешние сервисы будут добавлены позднее,
секреты должны поступать только через переменные окружения, а вызовы — иметь
таймаут, обработку ошибок и полноценный локальный fallback.

## Локальный публичный контракт `env`

Этот контракт описывает текущий код команды; его нужно сверить с официальным
пакетом при получении.

| Член | Тип и содержимое |
| --- | --- |
| `customer_profile` | Копия pandas DataFrame: `customer_id`, `current_tariff`, `arpu_segment`, `data_segment`, `call_segment`, `predicted_arpu` |
| `tariffs` | Копия pandas DataFrame: обязательные `tariff_id`, `monthly_fee`; генератор также добавляет `data_gb`, `minutes` |
| `channels` | Словарь `{channel: {"cost": cost_per_contact}}` |
| `remaining_budget` | Остаток бюджета после пилотов |
| `remaining_contacts` | Остаток контактов после пилотов |
| `pilots_left` | Остаток количества пилотов |
| `pilot_history` | Копия списка результатов проведённых пилотов |
| `run_pilot(...)` | Проведение пилота и списание его ресурсов |

Локальные каналы: `push` — 0, `sms` — 4, `digital_ads` — 22,
`call` — 160 условных единиц за контакт. Агент читает доступные каналы,
стоимость и тарифы из `env`, а не задаёт эти значения самостоятельно.

```python
result = env.run_pilot(
    target_tariff=tariff_id,
    channel=channel_name,
    n_customers=60,
    filter_arpu_segment="HIGH",
    filter_data_segment="HEAVY",
)
```

Результат содержит `pilot_id`, `n_customers`, `mean_arpu_uplift`,
`std_arpu_uplift`, `communication_cost`, `net_gain`, тариф, канал и переданные
фильтры. Среднее и стандартное отклонение — **абсолютное изменение ARPU на
абонента**, не процент; стандартное отклонение выборочное (`ddof=1`).

`Agent.act(env)` возвращает список словарей кампаний. Поля:
`campaign_name`, `target_tariff`, `channel` и необязательные фильтры
`filter_arpu_segment`, `filter_data_segment`, `filter_call_segment`,
`filter_current_tariff`. Фильтры соответствуют одноимённым столбцам профиля
без префикса `filter_`. Значения внутри фильтра разделяются `;` и объединяются
через ИЛИ; разные фильтры — через И. Пустой или отсутствующий фильтр означает
всю соответствующую категорию. Неизвестные значения и поля отвергаются.
Размер финальной кампании определяется фильтрами; поля для произвольного
обрезания аудитории нет.

## Лимиты и локальный результат

| Ограничение | Значение |
| --- | --- |
| Финальные кампании | От 1 до 10 |
| Абоненты на финальную кампанию | Не более 5 000 |
| Все контакты, включая пилоты | Не более 15 000 |
| Все расходы, включая пилоты | Не более 100 000 |
| Успешные пилоты | От 1 до 20 |
| Абоненты в каждом пилоте | От 10 до 200 |
| Локальное выполнение | Таймаут дочернего процесса до 600 секунд |

Каждый повторный контакт расходует контактный лимит и бюджет. До применения
финальных кампаний среда проверяет весь план. В локальном расчёте на каждого
уникального затронутого абонента учитывается лучший эффект среди его пилотных
и финальных контактов. Первый отрицательный эффект сохраняется отрицательным;
нулевой эффект необработанного абонента его не заменяет.

`net_gain = сумма этих эффектов − стоимость всех контактов`.
`total_arpu_after_costs = сумма predicted_arpu по базе + net_gain`.
Это метрики локальной модели, а не прогноз судейского балла.

Сценарий `mixed` создаёт случайные смешанные эффекты, `adverse` — неблагоприятные,
`channel_shift` — перестановку откликов между каналами. Изменение seed меняет
синтетические эффекты. Эти сценарии проверяют устойчивость исполнения и учёт
плохих исходов; они не доказывают качество на неизвестных данных.

## Безопасность и типовые проблемы запуска

Не коммитьте `.env`, credentials и персональные выгрузки; `.gitignore` уже
исключает окружения и временные результаты. Запрещены обход пилотов, извлечение
скрытых эффектов, обращения к чужим ресурсам и сетевые атаки. Подробности и
границы проверок — в [SECURITY.md](SECURITY.md). Не публикуйте значения окружения.

Если preflight сообщает `git-file-list-unavailable`, сначала проверьте
доступность Git и владельца **своей** рабочей папки. Для известного вам репозитория
с несовпадением владельца разрешите только текущую папку и только в этой сессии:

```powershell
$env:GIT_CONFIG_COUNT = '1'
$env:GIT_CONFIG_KEY_0 = 'safe.directory'
$env:GIT_CONFIG_VALUE_0 = (Get-Location).Path.Replace('\', '/')
python scripts/preflight.py
```

Не используйте wildcard для safe.directory. Если уже настроены переменные
GIT_CONFIG_*, используйте новую сессию, чтобы не перезаписать нужные настройки.
Отсутствие NumPy/pandas обычно означает запуск не из установленного venv.
Ошибка загрузки pip требует восстановления доступа к индексу пакетов; она
не должна маскироваться использованием ранее установленных глобальных библиотек.

## Известные ограничения и лицензии

- Официальный env и формат сдачи нужно проверить по пакету организаторов.
- Разведка ограничена 20 пилотами и может пропустить лучший тариф/канал.
  Сужение аудитории переносит оценку с более широкого пилота и может дать смещение.
- При недостатке ресурсов или отсутствии представимой группы агент сообщает
  ошибку. Даже допустимый план может дать отрицательный результат.
- Дедлайн агента 540 секунд проверяется между пилотами и не прерывает зависший
  чужой env. Локальный evaluator прерывает процесс по timeout до 600 секунд;
  запуск и очистка процесса могут немного увеличить полное время команды.
- Прямые версии закреплены; транзитивные зависимости не полностью зафиксированы.
  Чистая установка проверена на Windows/Python 3.12, не на всех платформах.
- Mock-среда — тестовый инструмент, не защищённая песочница и не судейская среда.

Версии, назначение и официальные источники лицензий — в
[THIRD_PARTY.md](THIRD_PARTY.md). Лицензии библиотек не определяют лицензию
кода команды: отдельного LICENSE проекта в текущем репозитории нет.
Демо и подготовка к сдаче: [сценарий](docs/demo-script.md),
[чек-лист перед 18:00](docs/final-checklist.md). Финальная интеграция и слияние
PR выполняются капитаном после отдельного подтверждения.
