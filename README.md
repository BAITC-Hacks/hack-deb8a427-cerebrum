# Cerebrum — агент тарифных маркетинговых кампаний

Агент для аналитика маркетинга в учебном кейсе Beeline. `Agent.act(env)`
проверяет аудитории, тарифы и каналы через пилоты и возвращает 1–10 кампаний.
Сценарий работы: импорт данных → проверка агента → экспорт `submission.csv`.

## Как работает

`candidates.py` ранжирует тарифы по цене и истории смен. `agent.py` строит
аудитории по публичным сегментам, проводит пилоты через `env.run_pilot()`,
уточняет оценки повторными пилотами и проверяет другие каналы при положительных
наблюдениях. Финальный план учитывает результаты пилотов, неопределённость и
остатки ресурсов. Если положительной оценки нет, выбирается малая часть
аудитории прошедшего пилота. Без успешного пилота или допустимого плана
агент сообщает об ошибке.

Среда, мок-эффекты, подсчёт результата и скрипты запуска взяты из пакета
организаторов без изменений. Подробнее: [архитектура](docs/architecture.md)
и [контракт API и лимиты](docs/constraints.md).

## Установка и данные

Нужны Git, Python 3.11+ и каталог официального пакета `beeline_case_participants`,
полученный у организаторов. [requirements.txt](requirements.txt) закрепляет
NumPy 2.3.5 и pandas 3.0.1 для работы с массивами и таблицами.

Команды ниже выполняются из корня репозитория в Windows PowerShell:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python -m pip check
```

Если `python` открывает Microsoft Store, укажите путь к установленному Python
в команде создания окружения. Если активация запрещена политикой PowerShell,
далее используйте `.\.venv\Scripts\python.exe` вместо `python`.

Замените путь ниже на каталог полученного пакета:

```powershell
python scripts/import_participant_package.py --source 'C:\path\to\beeline_case_participants'
python scripts/import_participant_package.py --check
```

Импорт сверяет SHA-256 с `scripts/participant_package_manifest.json`, копирует
семь CSV в корень и `data/`, не перезаписывая отличающиеся данные.
Входные CSV исключены из Git. `customer_profile.csv` содержит целевую аудиторию,
`data/change_tariff.csv` — историю другой выборки. Остальные файлы и поля — в
[описании пакета](PARTICIPANT_GUIDE.md#6-данные).

Без истории агент использует параметры тарифов, но официальной мок-среде
`data/change_tariff.csv` необходим. Для полного набора проверок нужен весь пакет.

## Запуск, проверка и экспорт

```powershell
python scripts/preflight.py
python -m unittest discover -s tests -v
python local_eval.py
python local_eval.py --runs 10
python make_submission.py
python scripts/preflight.py
git diff --check
```

Одиночный evaluator использует seed 42, серия — seed 0–9. Читайте отчёт:
исключение агента или `FAIL` могут сопровождаться кодом возврата 0. Проверьте
пилоты, лимиты и отсутствие отброшенных кампаний. Поле «Кампаний» включает
пилоты; лимит 10 относится к финальному плану.

`make_submission.py` запускает агента с seed 42 и **перезаписывает**
`submission.csv` в текущем каталоге. Экспортёр сам не подтверждает допустимость
плана. Для проверки воспроизводимости повторите экспорт и сравните хеши:

```powershell
Get-FileHash submission.csv -Algorithm SHA256
python make_submission.py
Get-FileHash submission.csv -Algorithm SHA256
Get-Content submission.csv
git status --short -- submission.csv
```

Хеши должны совпасть. Сдавайте проверенный CSV с `agent.py`, `candidates.py`
и `requirements.txt`. Локальный аудит: `python scripts/security_audit.py`.
Подробнее: [SECURITY.md](SECURITY.md) и [план проверок](docs/test-plan.md).

## Ограничения, сервисы и лицензии

- Данные пакета синтетические. Мок-эффекты отличаются от эффектов судейства;
  локальный результат не является прогнозом балла или реального бизнеса.
- Оценка неопределённости эвристическая. При плохих пилотах возможен убыток.
  Дедлайн 540 секунд проверяется между пилотами и не прерывает зависший вызов
  `env.run_pilot()`; принудительного таймаута в официальном evaluator нет.
- Внешних API и LLM в агенте нет, поэтому их недоступность на запуск не влияет.
  Переменные окружения не требуются. `OPENAI_API_KEY` в `.env.example`
  зарезервирован для будущего использования; агент его не читает и `.env`
  автоматически не загружает. Не записывайте секреты в код, логи или CSV.
- Прямые версии зависимостей закреплены; транзитивные версии и хеши пакетов
  не зафиксированы. Работа на Linux/macOS не подтверждена.
- Отдельной лицензии собственного кода нет. NumPy и pandas используют
  BSD-3-Clause; сведения о компонентах и их лицензиях — в
  [THIRD_PARTY.md](THIRD_PARTY.md). Права на распространение пакета и входных
  CSV нужно уточнять у организаторов; синтетический характер данных сам по
  себе не даёт разрешения на публикацию.
