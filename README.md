# Cerebrum — агент тарифных маркетинговых кампаний

Агент для аналитика маркетинга в учебном кейсе Beeline. Он исследует аудиторию
пилотами и возвращает 1–10 кампаний: кому предложить тариф и через какой канал.
План учитывает стоимость контактов, неопределённость и общие лимиты ресурсов.
Данные синтетические; локальный результат не предсказывает судейский балл.

## Быстрый запуск для жюри

Нужны **Python 3.11+**, ZIP или каталог официального пакета участников и интернет
для первой установки зависимостей. Скачайте репозиторий и откройте его каталог.
Git для запуска из скачанного ZIP не требуется.

**Windows:** дважды нажмите `start.cmd` и укажите путь к пакету, когда появится
приглашение. Либо выполните одну команду из корня проекта:

```powershell
python run.py --package "C:\path\to\beeline_case_participants.zip"
```

На Linux/macOS используйте `python3 run.py --package /path/to/participant.zip`.
Файл может называться иначе; вместо ZIP можно передать распакованный каталог.

Запуск создаёт локальное `.venv`, устанавливает закреплённые зависимости,
проверяет SHA-256 пакета, импортирует семь CSV и открывает
**[панель Cerebrum](http://127.0.0.1:8765/)**. Активация PowerShell не нужна.
Официальные файлы среды сохраняются без изменений. Отличающиеся локальные
данные не перезаписываются. Входные CSV и ZIP исключены из Git.

Повторный запуск: `python run.py` или `start.cmd`; пакет указывать повторно
не нужно. `start.cmd` автоматически использует созданную `.venv`.
Закрыть сервер — `Ctrl+C` в окне запуска. Если порт занят:
`python run.py --port 8766`. На сервере без браузера: `python run.py --no-browser`.
Если `python` открывает Microsoft Store, используйте `py -3` или путь к Python.

### Что посмотреть в панели

1. Нажмите **«Запустить агента»**, измените seed и сравните результат.
2. **«Кампании»** показывает аудитории, тарифы, каналы и позволяет скачать CSV.
3. **«История пилотов»** показывает шумные наблюдения и расходы.
4. **«Решения агента»** показывает разведку, уточнения, сравнение каналов и
   оценки неопределённости. Здесь же виден статус LLM или запасной логики.
5. **«Соответствие ТЗ»** показывает сохранённую серию проверок. При изменении
   алгоритма панель помечает отчёт устаревшим.

Панель доступна только на текущем компьютере. Для базового режима после
установки зависимостей интернет и API-ключ не требуются.

## Проверка и артефакты сдачи

Одна команда подготавливает окружение, проверяет seed 42 и 0–9 и дважды
запускает официальный экспортёр:

```powershell
python run.py --check
```

На Windows также можно выполнить `start.cmd --check`.

Она независимо проверяет формат плана, пилоты, аудитории и суммарные лимиты,
сопоставляет их с официальным скорингом и сравнивает CSV побайтно.
Каждый процесс оценки ограничен 600 секундами. Ошибка агента, отрицательный
результат или нарушение проверки дают ненулевой код возврата.

Выход: `submission.csv`, `artifacts/validation.json`, `artifacts/latest.json`.
Режим проверки всегда **без LLM**, чтобы экспорт воспроизводился. Команда
перезаписывает `submission.csv`; просмотрите его перед коммитом и сдачей.
Состав решения: `agent.py`, `candidates.py`, **`llm_advisor.py`**,
`requirements.txt` и проверенный `submission.csv`.

Официальные команды остаются доступны в подготовленном окружении:

```powershell
.\.venv\Scripts\python.exe local_eval.py
.\.venv\Scripts\python.exe local_eval.py --runs 10
.\.venv\Scripts\python.exe make_submission.py
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
.\.venv\Scripts\python.exe scripts/preflight.py
```

При активированном окружении: `python local_eval.py`. На Linux/macOS путь к
интерпретатору — `.venv/bin/python`. Сам официальный evaluator может вернуть
код 0 при ошибке: читайте его отчёт. Поле «Кампаний» включает пилоты; лимит
10 относится к финальному плану. Для разработки с уже установленными
зависимостями доступен `python run.py --use-current-env`.

## Опциональные возможности ТЗ

| Пункт | Реализация и проверка |
| --- | --- |
| Учёт неопределённости | Накопленные наблюдения дают среднюю оценку и стандартную ошибку. Финальный план ранжируется по нижней оценке чистого эффекта. Для официального API без выборочной дисперсии используется консервативная модель неопределённости. |
| Адаптивная разведка | Первые пилоты малы; неоднозначные гипотезы уточняются выборками до 200. Число пилотов сокращается, когда подходящих гипотез или ресурсов больше нет. |
| Выбор каналов | Цена и публичный коэффициент канала определяют приоритет эксперимента. Платный канал сначала проходит собственный пилот; тесты проверяют выбор SMS и звонка при разных наблюдаемых эффектах. |
| Устойчивость | `--check` проверяет каждый seed отдельно, положительность результата и общие лимиты. Тесты дополнительно моделируют отрицательные эффекты, ошибки пилотов и малые аудитории. |
| LLM в принятии решений | Опционально меняет порядок гипотез для реальных пилотов. Строгая проверка ответа, один запрос, максимум 8 секунд ожидания, локальная запасная логика. |

Оценка неопределённости эвристическая: её нельзя называть калиброванным
доверительным интервалом. Положительные локальные прогоны не доказывают
оптимальность стратегии или устойчивость к любым скрытым эффектам.

### Включение LLM

Передайте `OPENAI_API_KEY` через окружение процесса и запустите:

```powershell
python run.py --llm
```

Используется OpenAI Responses API, модель `gpt-4.1-mini-2025-04-14`;
`OPENAI_MODEL` позволяет выбрать другую совместимую модель. Для запуска
официальных скриптов в этом режиме установите также `CEREBRUM_LLM=1`.
`.env` автоматически не загружается; секреты в код, CSV и логи записывать
нельзя. API-вызовы оплачиваются по тарифам провайдера.

Модель получает агрегаты до 20 сегментов: фильтры, размеры, средний ARPU и
варианты тарифов. Строки абонентов и их ID не передаются. Ответ может только
переставить допустимые гипотезы; окончательные кампании требуют пилотных
наблюдений и проходят проверку лимитов. При ошибке, таймауте, отказе, неверном
ответе или отсутствии ключа агент продолжает с локальным ранжированием.
Результат живой модели может меняться, поэтому воспроизводимый CSV сдачи
генерируется без LLM. Живой запрос проверен: HTTP 200, порядок гипотез применён,
официальный evaluator дал PASS. На одном seed 42 получено +372 925,00 у.е.
против +389 987,36 без LLM: преимущество по прибыли не подтверждено.

Контракт API: [Structured Outputs](https://developers.openai.com/api/docs/guides/structured-outputs)
и [модель](https://developers.openai.com/api/docs/models/gpt-4.1-mini).

## Устройство проекта

```text
run.py → .venv и импорт пакета → preview_server.py → jury_eval.py
                                                      ↓
                                  официальный local_eval.py → Agent.act(env)
                                                                  ↓
                                        candidates.py + llm_advisor.py
```

`agent.py` использует только публичный API среды, открытую историю и пилоты.
История относится к другой выборке и используется для выбора гипотез, а не
как известный эффект текущих клиентов. Без истории работает ранжирование
по параметрам тарифов; официальной мок-среде файл истории необходим.
`jury_eval.py` проверяет решения и готовит отчёт. Интерфейс — HTML/JS без сборки
Node.js. Прямые зависимости: NumPy 2.3.5 и pandas 3.0.1.

Подробности: [архитектура](docs/architecture.md), [лимиты](docs/constraints.md),
[профиль пакета](docs/participant-data-profile.md),
[результаты доработки](docs/jury-validation.md), [безопасность](SECURITY.md),
[источники и лицензии](THIRD_PARTY.md).
Отдельной лицензии кода команды нет; права на распространение официального
пакета нужно уточнять у организаторов. Чистая установка и запуск проверяются
на Windows; Linux/macOS требуют отдельной проверки.
